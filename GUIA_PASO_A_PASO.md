# Guía de entrega
1. Descomprime el ZIP.
2. Abre Terminal y entra a la carpeta (escribe `cd ` y arrastra la carpeta).
3. Ejecuta `npm ci`, `npm run build`, `npm test`. Guarda captura del resultado.
4. Ejecuta `npm run demo:crear` y `npm run configurar:designfile`.
5. Abre Finder en `demo/Proyecto_Maestranza_EJEMPLO`.
6. Abre OpenCode en esta carpeta. Pide: «Usa listar_archivos y muéstrame qué archivos hay».
7. Pide crear carpetas y confirma expresamente. Después pide organizar archivos y confirma expresamente.
8. Enseña el antes y después en Finder y graba la pantalla.
9. Crea repositorio público de GitHub, haz varios commits reales y publica el proyecto sin datos privados.
10. Entrega URL del repositorio, video, texto de utilidad y declaración de IA.

Importante: esta entrega no incluye prueba en tu Mac ni publicación en tu cuenta de GitHub.
